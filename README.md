# 蜜源植物群落过程式生成工具(蝴蝶园生境设计)

Svelte 4 + WebGPU(自动回退 Canvas2D)的蜜源植物群落过程式生成与教学考核工具。

## 运行

```bash
npm install
npm run dev      # 开发 http://127.0.0.1:5173
npm run build    # 构建到 dist/
node test-gen.mjs  # 逻辑自测:确定性 / 锁定保留 / 覆盖率统计
```

## 功能

- **参数化生成**:地块长宽、坡向、水系位置与带宽、群落密度、春夏秋三季花期权重、裸石比例、随机种子
- **确定性**:同一组参数 + 同一种子,生成结果完全一致(`test-gen.mjs` 可验证)
- **分层排布**:乔木层 / 灌木层 / 蜜源花草层按高度与冠幅依次定植,品种选择受花期权重、湿度(距水系距离)、光照(坡向)共同影响;裸石斑块由确定性噪声生成
- **锁定机制**:手动移动的植株、手工补种、批量替换的植株自动打锁定标记(金色圈);重新生成时锁定株保持原位,仅重排其余
- **三套花期视图**:春 / 夏 / 秋切换,实时显示开花覆盖率
- **交互**:点击查看品种/株高/花期/同种数量;移动模式拖拽植株;补种模式点击种植;框选模式批量替换品种
- **统计输出**:植物配置表(品种/层次/数量/面积/花期)与面积统计,均可导出 CSV
- **存档**:种子 + 参数 + 全部植株(含锁定)存入 localStorage,可命名调出
- **教学考核**:老师以当前参数+种子+三季覆盖率为标准答案出题;学员领题作答后提交,系统按参数比对(40 分)+ 三季覆盖率偏差(60 分)自动评分并列出错题点;老师可复核改分、写备注;成绩汇总表可导出 CSV

## 渲染

优先 WebGPU(实例化绘制植株、程序化地形/水系背景、裸石三角网格),不支持时自动回退 Canvas2D,功能一致。

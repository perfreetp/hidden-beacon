# 烟气监测立面生成与档案加工台

面向生物质电厂烟气监测设备巡检的**立面过程式生成**与**档案加工**工作台。
巡检员输入厂区走廊参数即可自动生成脱硫塔、布袋除尘器、烟囱监测平台、采样探头、
管廊、爬梯的立面排布，并支持微调加锁、版本对比、审核归档与档案检索导出。

技术栈：**Svelte 5（runes）+ Vite + SVG + D3（zoom 交互）+ svelte-spa-router**，
纯前端、零后端，档案持久化在浏览器 `localStorage`。

## 运行

```bash
npm install
npm run dev      # 开发，默认 http://127.0.0.1:5173
npm run build    # 生产构建到 dist/
npm run preview  # 预览构建产物
node scripts/selftest.mjs   # 生成引擎自检（26 项）
```

## 四个页面

| 路由 | 页面 | 职责 |
| --- | --- | --- |
| `#/` | ① 生成页 | 输入跨度/层高/开间数/设备间距/管径/种子，自动分格、布置设备轮廓、连管线、标注；只读预览，入库后进入编辑 |
| `#/edit` | ② 编辑页 | 框选、平移、缩放；点选拖拽微调并吸附最近轴线/层高线，调整后自动加锁；批量换型号；设备/管线/标注/网格图层显隐；构件清册与挂点高度 |
| `#/review` | ③ 审核页 | 任选两个版本对比，新增（绿）/删除（红虚幽灵）/移动（琥珀）描边；变更摘要与明细；写审核意见，通过即归档、退回可改 |
| `#/archive` | ④ 档案页 | 按厂区、设备类型、生成参数、日期区间、状态检索；展开版本；导出 SVG 与巡检记录报告 |

## 核心机制

### 确定性生成（`src/lib/engine/`）
- `prng.js`：字符串种子 → 32 位哈希（xFnv 变体）→ mulberry32 伪随机。
  **同参数同种子字节级一致**，换种子只改变开间内的抖动布局。
- `generate.js`：按开间轴网（轴线 = 开间边界，层高线按最高烟囱反推总高）轮换布置
  脱硫塔/布袋，末开间固定烟囱；每开间配管廊、爬梯，主设备附采样探头；
  再生成垂直烟管、屋面主烟管、管廊支管与探头引线。
- `shapes.js`：六类设备的立面图例基元（SVG primitives），画布渲染与文件导出共用一套符号。
- `catalog.js`：六类设备各 2–3 个型号（米制外形尺寸），支撑批量换型。

### 拖拽微调 + 吸附 + 锁定
- 世界坐标 y 轴向上，外层 d3 zoom transform 负责平移缩放，内层 `scale(1,-1)` 翻转。
- 拖拽时 `liveSnap` 实时求最近轴线（x）与层高线（y），进入阈值才吸附、否则跟手，
  并显示蓝色吸附参考线；松手即把该构件 `locked=true` 持久化。
- **带锁重生成**：`generate(params, prev)` 对同 id 构件，锁定者整体保留旧几何，
  未锁定者按新参数重排；开间缩小时被删开间里的锁定构件作为孤儿保留。

### 版本与差异（`diff.js` / `repo.js`）
- 每次"保存为新版本"生成不可变快照；`diffFacade` 按 id 比对几何，
  输出 added / removed / moved / same 四类及计数。
- `repo.js` 用 Svelte store + localStorage 持久化项目、版本、审核结论；
  首次打开注入一个含两版本的演示项目。

### 导出（`export.js`）
- `buildSvg`：独立可打开的 SVG 文件（含图框、参数、轴网、图例，差异描边可选）。
- `exportReport`：自包含 HTML 巡检记录报告（参数表、内嵌立面图、变更摘要、
  设备/管线清册、审核意见），可直接浏览器打印为 PDF。

## 目录结构

```
src/
├── lib/
│   ├── engine/
│   │   ├── prng.js       # 种子哈希 + mulberry32
│   │   ├── catalog.js    # 设备类型与型号库
│   │   ├── generate.js   # 过程式生成、网格、吸附、带锁合并
│   │   ├── shapes.js     # 立面图例 SVG 基元
│   │   └── diff.js       # 两版差异
│   ├── repo.js           # 项目/版本/审核的 store 与持久化
│   ├── export.js         # SVG 与巡检报告导出
│   └── session.js        # 跨页面当前项目会话
├── components/
│   ├── FacadeCanvas.svelte   # SVG+D3 画布：缩放/平移/框选/拖拽吸附/差异渲染
│   └── TopNav.svelte
├── pages/                # 四个页面
└── App.svelte            # 路由外壳
scripts/
├── selftest.mjs          # 引擎单元级自检
└── cdp-e2e-*.mjs         # 基于 Chrome DevTools Protocol 的交互回归
```

## 已验证的交互回归（CDP）
- 同参数同种子结果一致；不同种子布局不同
- 锁定设备/管线在多次改参数重生成后坐标保持，未锁定部分重排
- 拖拽单点构件只锁定该构件；多选拖拽批量锁定
- 框选命中设备与管线；批量换型号整体改尺寸且保留位置中心
- 图层开关实时隐藏；审核通过后项目状态变 archived
- SVG（`image/svg+xml`）与 HTML 报告导出内容完整

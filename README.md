# 应力锥网格雕刻工作台

面向高压电缆终端附件结构设计的三维锥面轮廓雕刻工具。Svelte 4 + Babylon.js + Vite。

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 构建到 dist/
node smoke.mjs   # 核心逻辑冒烟测试（无需浏览器）
```

## 功能对照

| 需求 | 实现 |
|---|---|
| 基础回转体网格 | 打开即载入应力锥车削网格（8640 顶点 / 17088 面），顶栏实时显示顶点数、面数 |
| 左键起笔雕刻 | 左键拖拽；右键旋转、中键平移、滚轮缩放 |
| 四种笔刷 | 拉伸（grab）/ 平滑（Laplacian）/ 膨胀（沿法线）/ 压平（向起笔平面投影） |
| 半径 / 强度 | 滑杆调节（半径 2–30 mm，强度 0.05–1） |
| 软选择衰减 | 笔刷边缘按衰减曲线加权：线性 / 平滑（smoothstep）/ 锐利（三次方） |
| 轴向镜像 | 开启后过轴线的镜像点同步受力 |
| 母线锁 | 冻结根部 14 mm 区域并去除位移的轴向分量，防止带歪根部 |
| 笔划级撤销 | 起笔记快照，一次拖拽共用一个撤销单元；撤销/重做按笔划整体回退（Ctrl+Z / Ctrl+Y） |
| 实时法线 | 每次笔刷作用后重算顶点法线 |
| 显示模式 | 实体 / 线框 / 半透明叠显（带轮廓线） |
| 隐藏外屏蔽层 | 复选框切换外层半透明屏蔽层，便于观察内部锥面 |
| 封口边缘环保护 | 笔刷触及开口端边界环时提示并自动跳过，不会挑破边缘 |
| 对称轴偏移检测 | 逐截面环质心偏离平均轴线，> 0.5 mm 顶栏标红 |
| 导出 | OBJ 网格 + 记录文件（面数、包围盒尺寸、轴偏移） |
| 版本 | 「保存当前为版本」快照；任选两版本对比，网格按偏差热力图着色并给出最大/平均偏差 |

坐标约定：Y 轴为电缆轴向（对称轴），根部在 y=0，单位 mm。

## 结构

- `src/lib/cone.js` — 母线轮廓（Catmull-Rom）、车削网格、边界环/轴偏移/包围盒计算
- `src/lib/sculpt.js` — 雕刻引擎：笔刷、衰减、镜像、母线锁、边缘环保护、笔划撤销栈
- `src/lib/stage.js` — Babylon 场景：相机、灯光、锥体、外屏蔽层、对称轴参考线
- `src/App.svelte` — UI 与交互编排

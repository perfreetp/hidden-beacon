# 识字卡 · 距离场渲染台

给学龄前儿童做识字卡的图形渲染台。每张卡上的汉字和图形都由**有向距离场（SDF）**
生成轮廓，导出的是矢量，放大到任意倍数、打印到任意 DPI 边缘都保持锐利。

原生 TypeScript + Web Components，无框架。D3 负责缩放、平移、拖拽和等值线提取。

```bash
npm install
npm run dev       # http://127.0.0.1:5173
npm run build     # 类型检查 + 生产构建到 dist/
npm run preview
```

## 为什么是距离场

普通做法是把字体的矢量轮廓直接转成 `<path>`。这个项目多走一步，是为了让"形状"
成为可计算的对象：

1. **字形 → 距离场。** 字体轮廓被展平成多边形，构建带桶索引的多边形距离场；
   距离是精确的（最近边查询 + 扫描线内外判定），不是像素近似。
2. **距离场 → 等值线。** 在网格上采样后，用行走方块（d3-contour）提取
   `field = 0` 的等值线，得到拓扑正确的环。
3. **等值线 → 精确投影。** 每个顶点沿距离场梯度做阻尼牛顿迭代，落到精确的
   等值线上。网格只提供拓扑，最终坐标不受网格分辨率限制。
4. **环 → 平滑路径。** 保留尖角的 Catmull-Rom 样条转成 SVG 路径。转角处切线
   长度受相邻线段约束，长直边不会外凸。

峰值偏差在数值测试里是 **0.0 mm**：每个轮廓顶点都精确落在等值线上
（`tests/pipeline.test.ts`）。与字体原生栅格逐像素对比，IoU 为 94–96%，
剩余差异全部是 1 像素的抗锯齿边缘。

距离场同时被复用于两件普通轮廓做不到的事：

- **圆角底纹融合。** 每个圆角矩形是一个距离场，多个场用多项式平滑并集
  （smin）合成。融合距离就是 smin 的 `k`，拖动时形状像水滴一样连起来。
- **按轮廓的真实间距排布。** 两个字之间的距离用各自的轮廓场互测，不是外接框。
  所以"一"可以紧贴邻居，"國"会自动留出它需要的空间。

## 功能

**画布** — D3 缩放（滚轮/捏合，0.2×–60×）、平移（拖空白处）、拖动字形。
矢量渲染，缩放不重新栅格化。`0` 适应窗口，`+`/`-` 缩放，方向键移动
（Shift 加速），`Delete` 删除，`Ctrl+S` 存版本。

**字形** — 两种字体（站酷快乐体、霞鹜文楷），内置 4000 常用字子集。
字号、倾斜可调；最多 6 个字，足够一张卡的主题。

**效果** — 描边粗细、发光半径/强度/颜色、投影 X/Y/柔化/浓度/颜色，全部独立滑块。
实现上是分层 SVG：投影是模糊的偏移副本，发光是模糊的填充，描边画在填充下面
（`stroke-width` ×2，露出的只有外半个），所以调参数不重建几何。

**底纹** — 圆角矩形距离场融合。融合距离 0–24 mm，圆角半径、纸张色、底纹色、
颗粒、内框可选。"换一组圆角"重排布局。

**排布** — 一个按钮按距离场自动排布：单字居中；两字按卡片长宽比选横排或竖排；
三字竖排（或横卡上排成三角）；更多按网格。间隙精确等于设定的"字间距"，
不会偷偷摊开多余空间。整体越界时自动收缩到卡片内。

**版本** — 每次编辑静默 2.6 秒后自动存一个版本（只有内容真变了才存，
所以拖一次滑块只产生一个版本），也可以手动"存为版本"。时间线里重命名、
收藏、删除、双击还原。

**对比** — 选两个版本，叠加或并排查看。差异按**覆盖面积**计算而不是按元素 id：
两版都画过的墨迹是灰、只在旧版的是绿、只在新版的是红。所以把字挪了 2mm
会看到一绿一红两道月牙，而不是"元素移动了"这种没用的结论。

**导出** — PNG（300/450/600/900/1200 dpi，导出时从矢量栅格化）、SVG（纯矢量源
文件）、PDF（A4 分页，每页 2–4 张，真实毫米尺寸，带裁切线）。工程备份为 JSON。
全部卡片和版本存在本机 IndexedDB，不上传。

## 结构

```
src/
  core/
    flatten.ts    字体路径 → 平坦多边形（含二次/三次贝塞尔细分）
    field.ts      解析距离场：多边形（桶索引+扫描线）、圆、圆角矩形、环、
                  星、心、超椭圆，以及平滑并集
    vectorize.ts  等值线提取、精确投影、RDP 简化、保角样条 → SVG 路径
    scene.ts      单位尺寸轮廓缓存、元素世界坐标场/路径、底纹融合
    layout.ts     距离场排布求解器（横排/竖排/三角/网格 + 松弛）
    diff.ts       版本覆盖差异 → 红绿矢量区域
    fonts.ts      字体加载与字形归一化
  render/svg.ts   卡片 SVG 合成（分层效果、A4 打印页）
  store/          IndexedDB 持久化 + 可观察状态
  ui/             Web Components：舞台、检视器、时间线、对比、打印
  export/         PNG/SVG/PDF 导出
tests/            在 Node 里跑的数值测试（无需浏览器）
tools/            字体子集构建、TS 测试运行器
```

## 测试

数值核心不依赖 DOM，直接在 Node 里验证：

```bash
node tools/run-ts.mjs tests/field.test.ts      # 各种距离场的距离与内外判定
node tools/run-ts.mjs tests/pipeline.test.ts   # 轮廓精确性、融合、直线保持
node tools/run-ts.mjs tests/layout.test.ts     # 单位轮廓与缩放不变性
node tools/run-ts.mjs tests/diff.test.ts       # 覆盖差异的三个区域
node tools/run-ts.mjs tests/bench.ts           # 单字矢量化的耗时
```

一个汉字完整走完 SDF → 轮廓 → 路径约 15–25 ms，只做一次（按单位尺寸缓存），
之后缩放/拖动全是坐标变换。

## 字体

内置两款 OFL 授权字体，已子集化到 GB2312 一级字集（见 `public/fonts/LICENSE.txt`）。
重建：

```bash
pip install fonttools brotli
python tools/build-fonts.py --src <含源 TTF 的目录>
```

Chrome/Edge 111+、Safari 16.4+、Firefox 113+。

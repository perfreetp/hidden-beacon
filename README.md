# 山地徒步线路制图 · 矢量瓦片渲染器

Vue3 + SVG + D3 实现的矢量瓦片地图渲染器,面向山地徒步线路制图场景。

## 运行

```bash
npm install
npm run gen-tiles   # 生成演示瓦片数据到 public/tiles
npm run dev         # 启动开发服务器
```

## 功能

- **按需取瓦片**:按当前缩放级别计算视口覆盖的 XYZ 瓦片,从本地 `public/tiles/{z}/{x}/{y}.json` 异步加载,带 LRU 缓存
- **SVG 渲染**:步道 / 公路 / 水系用 SVG path 绘制(D3 line 生成路径),山体阴影用多边形色带做底图
- **样式表**:右侧面板按要素类型配置颜色、线宽、虚实、最小可见级别,响应式绑定,改动立即重绘
- **标注摆放**:按优先级排序做包围盒碰撞检测,放不下的标注自动降级为小圆点,圆点也冲突则隐藏;同一要素跨瓦片去重
- **视口裁剪**:缩放、旋转时只渲染视口内的瓦片
- **倾斜视角**:垂直压缩 + 分层偏移近似伪 3D
- **父级占位**:瓦片未加载到时用最近已加载祖先瓦片放大占位,跨级切换时旧级别瓦片淡出、新瓦片淡入
- **悬停交互**:高亮要素并提示名称与长度
- **稳定帧率**:拖拽平移用 requestAnimationFrame 合帧,拖拽中禁用要素指针命中、暂停标注重算

## 操作

拖拽平移 · 滚轮缩放 · 双击放大一级 · 右侧滑杆控制旋转 / 倾斜

## 瓦片数据格式

```json
{
  "z": 10, "x": 512, "y": 512,
  "layers": {
    "hillshade": [{ "id": "hs-0-1", "props": { "shade": 0.4 }, "rings": [[[x, y], ...]] }],
    "water":     [{ "id": "water-bailong", "props": { "name": "白龙溪", "length": 15.2 }, "geom": [[x, y], ...] }],
    "roads":     [...],
    "trails":    [...]
  }
}
```

坐标为瓦片内 0..4096。`scripts/gen-tiles.mjs` 合成一片山地区域(z6–z11)并按瓦片裁剪,最高级别故意缺失约 1/9 的瓦片以演示父级占位。

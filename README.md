# 🧱 形状搭建乐园(立体启蒙台)

家长陪 5~8 岁孩子玩形状搭建的立体启蒙应用:在 2D 网格画布上画封闭轮廓,一键变成立体积木,拼搭组合后可导出图片留念。

技术栈:**Vue 3 + Vite + Babylon.js**

## 运行

```bash
npm install
npm run dev      # 打开 http://localhost:5173
```

构建:`npm run build`,预览:`npm run preview`。

## 功能一览

| 功能 | 玩法 |
| --- | --- |
| 一笔画轮廓 | 在左侧网格画布按住拖动;点会吸附到网格和起点 |
| 闭合检测 | 首尾没接上时,缺口两端出现橙色圆点,点一下圆点自动补上 |
| 水平/垂直约束 | 画线接近水平或垂直时自动吸附,并出现 H / V 标记 |
| 拉伸成积木 | 闭合后右侧生成立体,**拖动黄色小球**实时拉厚(或用滑块) |
| 回转体 | 切到「旋转积木」,轮廓绕红色虚线轴旋转成型;**拖动绿色小球**或滑块调角度,15° 一档;轴线在画布上可左右拖动 |
| 倒角/圆角 | 选择「倒角」或「圆角」,用滑块调半径,绿色虚线预览实际轮廓 |
| 尺寸标注 | 闭合后显示宽/高标注,**双击数字**输入新值,实体跟着重算 |
| 复制拼搭 | 「复制一份」把当前积木放到旁边;点选任意积木即可拖动位置 |
| 穿模提示 | 积木之间互相穿插时,会以**红色轮廓**标出 |
| 视角 | 鼠标拖动环绕观看;一键正视 / 俯视 / 环绕 |
| 导出图片 | 「导出图片」把积木组合保存为 PNG 留念 |

## 代码结构

```
src/
├── App.vue                  主界面布局、控制面板、提示条
├── store.js                 共享状态(草图参数、积木列表、选中、穿模)
├── geometry.js              2D 几何:吸附、共线简化、倒角/圆角、缩放
└── components/
    ├── SketchPad.vue        2D 网格画布:一笔画、闭合检测、约束标记、尺寸标注
    └── Viewport3D.vue       Babylon 场景:拉伸/回转建模、手柄、穿模检测、导出
```

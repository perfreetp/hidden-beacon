# 古建修缮漫游运镜工具

基于 **Vue 3 + PlayCanvas** 的浏览器端漫游运镜工具：在程序化搭建的三重檐古建场景上编辑样条路径，驱动相机沿路径漫游，用于古建修缮巡检路线的预演与导出。

## 运行

```bash
npm install
npm run dev      # 开发服务器
npm run build    # 产物输出到 dist/
```

## 四个模块

| 模块 | 功能 |
|------|------|
| **路径编辑** | 在模型/地面上点击拾取控制点（≥6 个）；拖拽控制点移动、Alt+拖拽调高度、面板内可直接改坐标；切换闭合/开放路径；每段中点绘制切线箭头并列出切线向量与段长 |
| **朝向目标** | 为每个控制点绑定场景观察目标（塔刹/斗拱层/正殿匾额/石狮/经幢/移动飞鸟）；注视权重 1~5 档（决定相邻目标混合的影响范围）；目标跟随（实时追踪，含移动目标）或目标固定（锁定绑定瞬间坐标） |
| **速度曲线** | 5 档整体速度（0.8~5.0 m/s）；3 个关键帧速度倍率（位置 5%~95%、倍率 ×0.2~×3.0）；Canvas 预览 0~100% 行程的速度曲线，并给出速度范围、全长与预计全程时长 |
| **漫游** | 播放/暂停/停止、进度拖动；HUD 与面板实时显示当前段编号与剩余行程；相机衔接过渡时间 0.3~1.5 s；选择衔接点可预览前后两段朝向融合（红线=前段朝向，绿线=后段朝向） |

## 数据

- **导出**：顶栏「导出 roam.json」，包含路径控制点、朝向目标绑定、速度档位与关键帧、过渡参数。
- **导入**：顶栏「导入 JSON」恢复以上全部状态（含结构校验）。
- **持久化**：所有编辑自动防抖保存到浏览器 IndexedDB（库 `gujian-roam-tool`），刷新后自动恢复；首次打开载入一条环绕演示路径。

## 交互说明

- 左键点击模型/地面：添加控制点（路径编辑页）
- 拖拽控制点：水平移动；Alt+拖拽：调整高度
- 拖动空白处：旋转视角；滚轮：缩放；Delete：删除选中控制点；Esc：退出衔接预览

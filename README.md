# ✨ 魔法光影画板

给学龄前儿童的亲子光影创作画板：在暗色画布上用发光的粗笔刷涂画，盖上星星、小鱼、房子图章，再用一排可拖拽排序的「效果卡」给画面施魔法。

## 运行

```bash
npm install
npm run dev      # 开发服务器
npm run build    # 构建到 dist/
npm run preview  # 预览构建产物
```

需要支持 WebGL2 的浏览器（最新版 Chrome / Edge / Firefox / Safari）。

## 功能

- **画笔工具**：发光笔刷（颜色/粗细可调）、星星/小鱼/房子图章、抓手拖动
- **自动图层**：每一笔、每个图章自动拆成独立图层，可单独隐藏/删除
- **效果卡**（右侧，拖动 ⠿ 手柄实时改变计算顺序，画面立即重算）：
  - ✨ 泛光 —— 强度、扩散半径
  - 🔍 景深 —— 对焦点（滑杆或在画布上直接点选）、模糊范围、模糊强度
  - 🎨 色调映射 —— 柔和 / 鲜艳 / 夜色 三档
  - ✏️ 描边 —— 粗细、颜色
  - 每张卡可单独开关
- **分屏对比**：工具栏「⚖️ 对比」开启滑块，左右拖动对比加效果前后的同一帧
- **缩放/拖动**：滚轮缩放（以指针为中心），抓手工具或中键拖动，「🔭 复位视图」还原
- **高对比模式**：「👁 高对比」为色弱孩子增强画面对比度与饱和度
- **自动保存**：图层（笔画数据）、效果顺序与参数、视图、高对比开关都存入 localStorage，下次打开自动还原
- **导出**：一键导出 2× 高清 PNG（3200×2400）和一份 JSON 效果配置

## 技术要点

- **Svelte 4 + Vite**，无 UI 框架依赖
- **WebGL2 渲染管线**（`src/lib/gl/engine.js`）：
  - 每个图层一张 RGBA 纹理（FBO），笔刷用发光点精灵加法混合，图章用三角形填充 + 外发光
  - 效果按卡片顺序串联 ping-pong 计算：泛光（亮部提取 + 半分辨率分离高斯 + 叠加）、景深（径向距离混合清晰/模糊）、色调映射、描边（alpha 邻域边缘检测）
  - 最终 blit 统一处理视图变换、分屏对比、高对比
- **持久化**：保存的是笔画数据（点列）而非像素，重放即可还原，体积小且无损
- **测试**：`npm run dev` 后访问 `/test/smoke.html` 运行引擎冒烟测试（16 项断言）

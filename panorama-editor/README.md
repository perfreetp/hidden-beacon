# 供水泵站全景漫游编辑器

面向供水泵站现场勘察的全景漫游编辑工具：六张立方体面照片拼接成全景，在等距柱状展开图与透视画面中布置热点、设备标注与现场留言，并导出可交付的漫游包。

技术栈：**Vue 3 + SVG + D3 v7 + Canvas 像素级投影**，无 WebGL 依赖。

## 启动

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 生产构建
npm test           # 球面数学 + 接缝对齐测试 (纯 Node, 874+ 项断言)
```

打开后点右上角「载入演示数据」可立即体验两个带连接关系的演示点位。
带 `?demo=1` 参数访问会自动载入演示数据。

## 功能与实现要点

### 球面数学内核 (`src/lib/geo.js`)
- **经纬 ↔ 三维向量**互逆，经度 0° 为正北(+Z)，纬度 +90° 为天顶。
- **热点拖动球面反算**：屏幕坐标经相机正交基精确反投影成球面射线再转经纬，
  不做平面近似。测试覆盖 pitch ±85°、fov 20–110°，全视野拾取往返误差 **0.00000°（远优于 1° 要求）**，两极附近不拉伸跑偏。
- **大圆最短路径 slerp**：`slerpSpin()` 支持额外整圈旋转（0–2 圈可调），对跖点有正交轴兜底。
- **立方体面 ↔ 球面方向**：标准立方体贴图布局，面/uv 往返与 12 条公共棱边连续性均有测试。

### 六面拼接与接缝对齐 (`src/lib/cube.js`)
- 逐像素把六张面图重投影为等距柱状图（双线性采样）。
- **接缝颜色对齐**：采样 12 条公共棱边两侧颜色，对每条棱建立 `g_a·c_a = g_b·c_b` 约束，
  锁定基准面后按 RGB 三通道最小二乘求解各面增益（高斯消元）。
  合成数据测试验证可精确还原曝光差异的倒数校正量。

### 透视视口 (`src/components/PanoView.vue` + `src/lib/viewRenderer.js`)
- Canvas 逐像素精确反投影渲染等距柱状源图，相机空间射线 LUT 按 fov/尺寸缓存。
- 交互拖动时降采样保证流畅，停止后全分辨率重绘。
- 环视拖动按 Rodrigues 公式绕世界竖直轴/相机右轴做真三维旋转。
- SVG 叠加层渲染热点、设备标注（带随视角转动的朝向箭头）、留言气泡。
- 滚轮缩放、方向键微调、点热点触发飞行动画并在中途切换点位贴图。

### 等距柱状展开图 (`src/components/EquirectMap.vue`)
- D3 `geoEquirectangular` + `geoGraticule` 绘制 15° 经纬网格、赤道/本初子午线加粗。
- **当前视锥投影框**：用与主视图同一套反投影函数求视野四角，D3 geoPath 自动处理 ±180° 经线切割，
  方向键/指南针/滑块改变视角时投影框实时跟随。
- 展开图上可直接放置/拖动热点、标注、留言，经纬度实时显示。

### 视角联动与过渡 (`src/components/CompassPanel.vue`)
- 可拖拽指南针、FOV(20–110°) 与俯仰滑块、过渡时长(200–4000ms)、额外旋转圈数。
- 飞行动画带进度条，easeInOutQuad 缓动。

### 数据与漫游包 (`src/store/editor.js`)
- 点位/热点/标注/留言全部 reactive 管理，坐标只存经纬。
- **导出漫游包**：单个 JSON，含全部点位、六面图与等距柱状图（dataURL 内嵌）、
  热点、标注、留言、接缝增益和连接关系 `links`。
- 支持漫游包重新导入，往返测试通过。
- 连接关系用 D3 力导向图可视化 (`ConnectionGraph.vue`)，点击节点跳转点位。

## 目录结构

```
src/
  lib/
    geo.js            # 球面/相机/立方体数学内核 (纯函数, 可 Node 测试)
    cube.js           # 六面拼接 + 接缝最小二乘对齐
    viewRenderer.js   # 透视画面像素级投影渲染
    demo.js           # 程序化演示贴图与数据
  store/editor.js     # 全局状态、飞行过渡、导入导出
  components/         # PanoView / EquirectMap / CompassPanel / PointPanel / PropertyPanel / ConnectionGraph
scripts/
  test-geo.mjs        # 球面数学测试 (874 断言)
  test-seam.mjs       # 接缝增益反解测试
```

## 现场使用流程

1. 新建点位，按 `+X 东 / -X 西 / +Y 上 / -Y 下 / +Z 北 / -Z 南` 上传六面照片，自动拼接。
2. 用「热点」工具在画面或展开图上放置跳转热点并在属性面板指定目标点位。
3. 用「设备标注」工具标注泵机/阀门/配电柜，设置朝向角（箭头随视角转动）。
4. 切「留言」工具，同事在画面上点一下即可留一句话。
5. 调整过渡时长与旋转圈数，点热点预览球面最短路径跳转。
6. 导出漫游包 JSON 交付。
